# Lavo CRM for Cursor / Grok Bot

Official MCP connector for [Lavo CRM](https://lavocrm.com) — the CRM built for pressure-washing companies.

## What you get

After you Connect and Approve with your Lavo CRM account, your agent can work with:

- Customers and properties
- Quotes and jobs
- Schedule / visits
- Invoices and payments

## Install

1. Install this plugin from the Cursor Marketplace (or add the MCP URL below).
2. Click **Connect** / **Authenticate** on **Lavo CRM**.
3. Sign in at Lavo CRM and press **Approve**.
4. Ask your agent about today's schedule, open quotes, or a customer.

## MCP endpoint

```
https://api.lavocrm.com/functions/v1/mcp
```

Auth is OAuth 2.1 via your Lavo CRM login. No personal access token required for the normal Connect flow.
